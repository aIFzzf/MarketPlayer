### 问题1: agent_status表为空 ✅ 已修复

**根本原因**: agent_status表缺少agent_name的唯一约束，导致`ON CONFLICT`语句无法工作

**修复方案**:
```sql
CREATE UNIQUE INDEX idx_agent_name_unique ON agent_status(agent_name);
```
