## 一、核心发现

### 1. 大语言模型 (LLM) 驱动的投资研究

- **FinGPT** (AI4Finance-Foundation) - 开源金融大语言模型，支持投资研究自动化
- **WallStr.Chat** - AI研究助手，支持并行阅读数十个PDF文档，专注投行/对冲基金场景

### 2. 强化学习在量化交易的应用

- **FinRL** - 金融强化学习框架
- **TradeMaster** (NTU) - 基于强化学习的量化交易开源平台
- **Vibe-Trading** - "Your Personal Trading Agent"

### 3. 全栈量化框架

| 项目 | 特点 | 技术栈 |
|------|------|--------|
| Microsoft Qlib | AI驱动的量化投资平台，支持监督学习/市场动态建模/RL | Python |
| vnpy | Python开源量化交易开发框架 | Python |
| WonderTrader | C++一站式量化研发交易框架 | C++/Python |
| hikyuu | 超高速C++/Python量化框架 | C++ |
| zvt | 模块化量化框架 | Python |

### 4. AI 投资助手产品化趋势

- **InvestAI** - 监控趋势、规则触发、风险信号，保持投资理性
- **Kryptos AI** - 加密货币投资组合管理虚拟助手
- **FinGenius** - 开源AI金融助手，分析优化自动化财务决策

## 二、新兴特性与趋势

1. **多智能体系统** - AI驱动的多智能体系统生成专业投资研究报告
2. **实时新闻分析** - 结合实时新闻、财务指标进行投资研究
3. **自动化R&D** - Microsoft Qlib集成RD-Agent自动化研发流程
4. **低成本量化** - 面向个人投资者的开源工具增多
